# Contribuciones

¡Gracias por tu interés en contribuir a AdminLTE Dashboard! Aquí están las pautas para hacerlo.

## Cómo Contribuir

### Reportar Bugs
1. Verifica que el bug no haya sido reportado antes
2. Abre un issue describiendo:
   - El comportamiento esperado
   - El comportamiento actual
   - Pasos para reproducir
   - Tu ambiente (OS, PHP version, etc.)

### Sugerir Mejoras
1. Abre un issue con la etiqueta `enhancement`
2. Describe tu idea claramente
3. Proporciona ejemplos si es posible

### Pull Requests
1. Haz fork del repositorio
2. Crea una rama (`git checkout -b feature/AmazingFeature`)
3. Realiza tus cambios
4. Commit tus cambios (`git commit -m 'Add AmazingFeature'`)
5. Push a la rama (`git push origin feature/AmazingFeature`)
6. Abre un Pull Request

## Estándares de Código

- Usa PSR-12 para PHP
- Usa ESLint para JavaScript
- Añade tests para nuevas funcionalidades
- Actualiza la documentación

## Testing

Antes de hacer submit, asegúrate de:
1. Ejecutar `php artisan test`
2. Ejecutar `npm run build`
3. Verificar que no haya errores

## Licencia

Al contribuir, aceptas que tus cambios se licencien bajo la licencia MIT del proyecto.
